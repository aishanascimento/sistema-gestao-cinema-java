# 🎬 Sistema de Gestão de Cinema (Java)

## 📌 Visão Geral
Aplicação desenvolvida em Java utilizando os pilares da **Programação Orientada a Objetos (POO)** para simular o gerenciamento completo de um cinema. O sistema centraliza o controle de catálogo de filmes, sessões disponíveis e operações de bilheteria.

O projeto foi estruturado com foco em boas práticas de modelagem e na aplicação rigorosa de validações de regras de negócio.

## 🚀 Funcionalidades e Regras de Negócio

- **Gestão de Filmes e Sessões:** Cadastro e controle de exibições, horários e disponibilidade de assentos.
- **Validação de Restrições:** 
  - Bloqueio automático de vendas por lotação esgotada.
  - Validação de faixa etária para acesso às sessões.
- **Bilheteria Inteligente:** 
  - Utilização de **sobrecarga de métodos** (*method overloading*) para separar e organizar de forma limpa a lógica de cálculo de vendas de ingressos integrais e meia-entrada.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java
- **Paradigma:** Programação Orientada a Objetos (POO)
- **Conceitos Aplicados:** Encapsulamento, Sobrecarga de Métodos, Tratamento de Regras de Negócio e Estruturas de Decisão.
